# Score Priority V2 Plus Confused 640 80-Plus Attempt

Date: 2026-08-03
Base repo commit before implementation: `a34849f`

## Goal And Hypothesis

Prepare an 80-plus score attempt by combining:

- the proven `score-priority-v2 adaptive template` live path;
- a `640` candidate live-validated confused-deputy tail;
- no static EXFIL backstop.

The `+64` composition probe is still pending:

```text
55206257  Score priority v2 plus confused64  SubmissionStatus.PENDING
```

The reason to jump to `640` for an 80-plus attempt is arithmetic. A `512`
confused-deputy tail would be too tight if it simply matched the isolated 512
result:

```text
65.565 + 14.145 = 79.710
```

A `640` tail needs only `14.435` normalized points to clear `80`. Using the
observed isolated 512 confused-deputy rate, the expected combined public score
is:

```text
65.565 + 14.145 * (640 / 512) = 83.246
```

If the 640 tail scored perfectly linearly from the 64 micro canary, the upper
expectation would be:

```text
65.565 + 640 * 0.030 = 84.765
```

The risk is composition: previous mixed/static baskets have returned blank
public scores. This rung remains live-only and avoids static backstops, but it
is still a larger hidden-rerun load than the pending `+64` probe.

## Implementation

Added opt-in 640 combined aliases:

- `score-priority-v2-confused-640`
- `score_priority_v2_confused_640`
- `live-score-priority-v2-confused-640`
- `live_score_priority_v2_confused_640`
- `submission-score-priority-v2-confused-640`
- `submission_score_priority_v2_confused_640`

Defaults:

- score-priority v2 live cap: `1000`
- confused-deputy tail cap: `640`
- total candidate cap: `1640`
- tail start index: `1000`
- adaptive fast EXFIL: enabled
- static backstop: none

The `64` and `640` aliases share the same combined live runner. The candidate
set name selects the default tail cap.

confused-deputy replay with the EXFIL path.

## Decision

Discard this as a score ladder. Combined EXFIL plus confused-deputy is now
negative at small scale and invalid at larger scale. The next 80-plus attempts
should isolate confused-deputy and increase score per returned candidate rather
than mixing it with EXFIL.
